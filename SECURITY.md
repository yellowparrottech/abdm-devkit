# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it and the impact you expect. Never include real patient data, credentials, ABHA numbers, Aadhaar numbers or OTPs in a report.

We aim to acknowledge reports within 5 working days.

## Scope

In scope: code in this repository, including the integration core, MCP server, callback bridge and mock gateway.

Out of scope: ABDM or NHA systems themselves, and deployments operated by third parties. Report issues in ABDM services to NHA.

## Supported versions

The project is pre-release. Only the latest commit on `main` receives fixes.
